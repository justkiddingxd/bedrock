# Bedrock

Заметки и задачи в обычных markdown-файлах, как в Obsidian, плюс синхронизация со
сквозным шифрованием через общий или свой сервер. Ядро, сервер и бэкенд
приложения написаны на Rust, интерфейс — Tauri 2 + Svelte 5 + CodeMirror 6.

## Что умеет

- **Хранилище — обычная папка** с `.md` файлами. Подходит существующее хранилище Obsidian.
  Служебные данные лежат в `.bedrock/`, удалённое уходит в `.trash/`.
- **Редактор** с подсветкой markdown, кода в блоках, `[[вики-ссылок]]` и `#тегов`;
  автодополнение после `[[`, переход по ссылке Ctrl+клик, кликабельные чекбоксы,
  автосохранение. Режим просмотра (Ctrl+E).
- **Ссылки**: `[[Заметка]]`, `[[Папка/Заметка#Заголовок|текст]]`, `![[картинка.png]]`,
  обычные `[текст](Заметка.md)`. Обратные ссылки, исходящие, оглавление — в правой панели.
  При переименовании файла ссылки на него обновляются во всём хранилище.
- **Экран «Сегодня»** — главный: неделя с отметками дней, задачи на выбранный день,
  просроченные (переносятся на сегодня одной кнопкой), ближайшие задачи и заметка дня
  прямо на экране. Заметки дня лежат в `Дневник/ГГГГ-ММ-ДД.md`.
- **Задачи** из всех заметок: `- [ ] Позвонить 📅 2026-11-01 ⏫ #работа`
  (формат плагина Obsidian Tasks: `📅`/`due:` срок, `⏳` запланировано, `✅` выполнено,
  `⏫🔼🔽` приоритет). «Предстоящие» — по дням на неделю вперёд, потом «Позже» и «Без срока».
- **Заметка**: свойства из frontmatter над текстом, справа — кто ссылается сюда,
  исходящие ссылки, прогресс задач, содержание.
- **Ctrl+K** — одно окно для всего: заметки по названию, совпадения в тексте
  (`#тег` фильтрует по меткам), команды, создание новой заметки.
- **Синхронизация** в фоне: сразу после правок, по push-уведомлению сервера (SSE)
  и раз в минуту. Одновременные правки разных строк сливаются автоматически
  (трёхстороннее слияние), при конфликте одной строки ничего не теряется —
  создаётся копия `Заметка (conflict устройство дата).md`.

## Оформление

Спокойный нейтральный интерфейс: тонкие разделители вместо карточек и теней, один
акцентный цвет. Тёмная тема по умолчанию, светлая и «как в системе» — в настройках
(шестерёнка внизу боковой панели, Ctrl+,), там же акцент (кобальт, зелёный,
терракота, графит) и размер текста. Шрифт — Onest (свободный, с хорошей кириллицей),
вшит в приложение.

Окно без системной рамки: на Windows и Linux кнопки окна свои, справа сверху; на
macOS — нативные «светофоры» поверх контента (`tauri.macos.conf.json`).

## Шифрование

Сервер — «тупое» хранилище зашифрованных блобов, он не видит ни текста, ни имён файлов.

- У каждого хранилища случайный 256-битный ключ. На сервере он лежит зашифрованным
  ключом из пароля хранилища (Argon2id, 64 МиБ, 3 прохода → XChaCha20-Poly1305).
- Файл шифруется XChaCha20-Poly1305 вместе со своим путём; AAD привязывает блоб к
  хранилищу и файлу, так что сервер не может подменить один файл другим.
- Идентификатор файла — HMAC-SHA256 от пути, поэтому структура папок тоже скрыта.
- Пароль хранилища **нельзя восстановить**. Пароль аккаунта на сервере — отдельный.

## Структура

```
crates/core     хранилище, парсер, индекс, поиск, рендер, слияние   (bedrock-core)
crates/proto    типы HTTP API                                       (bedrock-proto)
crates/sync     шифрование, HTTP-клиент, алгоритм синхронизации     (bedrock-sync)
crates/server   сервер синхронизации: axum + SQLite                 (bedrock-server)
app/            десктоп-приложение: src-tauri (Rust) + src (Svelte)
```

## Запуск

Нужны Rust (stable), Node.js 20+, на Windows — WebView2 (есть в Windows 11).

```bash
cd app
npm install
npm run tauri dev      # приложение в режиме разработки
npm run tauri build    # установщик в target/release/bundle
```

### Свой сервер

```bash
cargo run --release -p bedrock-server -- --bind 0.0.0.0:8787 --data ./data
```

или в Docker:

```bash
docker build -t bedrock-server .
docker run -d -p 8787:8787 -v bedrock-data:/data bedrock-server
```

По умолчанию (`--registration first-only`) зарегистрироваться может только первый
пользователь — владелец. Для общего сервера на много людей:
`--registration open`. Другие параметры: `--max-file-mb`, `--name`; у всех есть
переменные окружения `BEDROCK_*` (см. `bedrock-server --help`). Снаружи ставьте
сервер за HTTPS (Caddy, nginx); для SSE отключите буферизацию прокси.

### Общий сервер

Адрес общего сервера вшивается в приложение при сборке и появляется в окне
синхронизации отдельной кнопкой:

```bash
VITE_SHARED_SERVER=https://sync.example.com npm run tauri build
```

## Тесты

```bash
cargo test --workspace --exclude bedrock-app
```

`crates/server/tests/sync_e2e.rs` поднимает настоящий сервер и гоняет синхронизацию
между тремя «устройствами»: загрузка, слияние, конфликт, удаление, переподключение,
перезапуск, и проверяет, что в базе сервера нет открытого текста и имён файлов.
